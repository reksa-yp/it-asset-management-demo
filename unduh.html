ASKER IT Asset Open source · MIT

Aset IT kantor, rapi dalam satu sistem.

Aplikasi web manajemen aset IT dan helpdesk: inventaris aset, ticketing, stok barang, mutasi aset, monitoring CCTV dan jaringan, serta export audit. Gratis dipakai dan boleh dikembangkan sendiri.

Fitur

Data AsetNomor aset otomatis, pengguna, lokasi, spesifikasi, software, aksesoris, label dan PDF.
Ticketing IT (diperbarui)User membuat tiket lengkap dengan foto masalah (kamera, galeri, atau tempel screenshot), admin memproses. Riwayat update dan detail pengerjaan tercatat.
Chat Grup (baru)Obrolan grup antar user terdaftar, tersimpan terenkripsi (AES-256): kirim foto (langsung dari kamera), balas, sebut @nama, dibaca oleh, grup pengumuman, bagikan kartu tiket/aset, dan temuan checklist CCTV terkirim otomatis.
Stok BarangBarang masuk dan keluar, rekap per kategori dan per user, peringatan restock.
Mutasi AsetSerah terima dan pemindahan aset dengan berita acara siap cetak.
Aset RusakDaftar aset rusak, lokasi penyimpanan, dan status perbaikannya.
Export AuditPilih sendiri data dan kolom yang diminta auditor, lalu export ke Excel.
Ganti Password PCPassword baru yang berbeda untuk tiap PC dan laptop, dengan daftar kerja.
Signature EmailGambar signature seragam untuk karyawan, warna mengikuti logo perusahaan.
Kop SuratLogo, nama, dan alamat perusahaan di semua dokumen cetak, PDF, dan file Excel. Diatur admin.
Scan QR AsetPindai label dengan kamera HP atau scanner USB untuk membuka detail aset.
CCTVMonitoring NVR realtime dengan live preview RTSP, notifikasi email, checklist harian digital (temuan otomatis jadi laporan perbaikan), laporan petugas bisa dipilih lalu dicetak/PDF, snapshot kamera, dan laporan bulanan per NVR dengan hari libur ditandai.
Jaringan (baru)Cek koneksi semua aset ber-IP sekali klik, topologi otomatis dengan kotak per lokasi dan warna kabel per switch/router, kotak bisa digeser bebas seperti Visio, hubungkan perangkat & ubah port langsung di diagram (ada peringatan port bentrok), peta port per switch, riwayat perubahan + batalkan, scan subnet, serta cetak/PDF/PNG.
Perangkat Jaringan & Printer (baru)Form dan import Excel khusus switch, router, dan AP: banyak IP per router, port eth/SFP, koneksi tambahan. Printer: USB atau LAN, milik perusahaan atau sewa.
Aman & tetap jalan tanpa internet (baru)Tampilan, QR label, dan scan QR berjalan dari server sendiri, jadi sistem tetap utuh di jaringan kantor saat internet mati. Ada batas percobaan login, penghapusan data terlindungi (CSRF), cookie sesi aman, dan folder upload yang tidak bisa menjalankan script.
Ext TeleponDaftar nomor extension kantor untuk admin dan user, siap cetak, PDF, atau Excel.
Praktis (diperbarui)Nyaman di HP dan laptop; di HP, menu user tampil sebagai tombol di bawah layar. Dua bahasa (Indonesia/English), import dan export Excel.

Cara memasang

  1. Unduh file ZIP di atas, lalu ekstrak ke htdocs, misalnya C:\xampp\htdocs\asker-it-asset.
  2. Jalankan Apache dan MySQL.
  3. Buka http://localhost/asker-it-asset/. Halaman instalasi terbuka otomatis.
  4. Isi data database, nama sistem, dan akun admin pertama, lalu klik Instal sekarang.
  5. Login, lalu hapus file install.php dari server.
  6. Opsional, untuk menu CCTV: tambahkan kategori aset CCTV dan NVR, isi data NVR di CCTV → Pengaturan, jalankan scripts\pasang_jadwal_cctv.bat sebagai administrator, dan pasang ffmpeg di server untuk live preview.

Panduan instalasi (PANDUAN_INSTALASI.md) dan panduan penggunaan bergambar 33 halaman (PDF) sudah ada di dalam ZIP.

Kebutuhan dan catatan

  • PHP 8.0 atau lebih baru dengan ekstensi pdo_mysql, mbstring, gd, zip, curl. ffmpeg hanya dibutuhkan untuk live preview CCTV.
  • MySQL atau MariaDB. XAMPP sudah cukup.
  • Menu Jaringan menjalankan ping dan arp di server lewat proc_open PHP, hanya saat tombol ditekan. Lihat PANDUAN_JARINGAN.md di dalam ZIP.
  • Pustaka pendukung sudah ada di dalam ZIP, tidak perlu composer install.
  • Dirancang untuk jaringan internal kantor. Jangan dibuka langsung ke internet tanpa pengamanan tambahan.
  • Username dan password PC pada data aset disimpan sebagai teks biasa (data referensi IT). Pertimbangkan sebelum mengisinya.
  • Lisensi MIT: bebas dipakai, diubah, dan dibagikan.

Tangkapan layar

Tangkapan layar diambil dari versi demo. Semua data di dalamnya adalah data contoh.

Coba dulu sebelum memasang
