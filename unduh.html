Aset IT kantor, rapi dalam satu sistem.

Aplikasi web manajemen aset IT dan helpdesk: inventaris aset, ticketing, stok barang, mutasi aset, monitoring CCTV dan jaringan, serta export audit. Gratis dipakai dan boleh dikembangkan sendiri.

Cara memasang

  1. Unduh file ZIP di atas, lalu ekstrak ke htdocs, misalnya C:\xampp\htdocs\asker-it-asset.
  2. Jalankan Apache dan MySQL.
  3. Buka http://localhost/asker-it-asset/. Halaman instalasi terbuka otomatis.
  4. Isi data database, nama sistem, dan akun admin pertama, lalu klik Instal sekarang.
  5. Login, lalu hapus file install.php dari server.
  6. Opsional, untuk menu CCTV: tambahkan kategori aset CCTV dan NVR, isi data NVR di CCTV → Pengaturan, jalankan scripts\pasang_jadwal_cctv.bat sebagai administrator, dan pasang ffmpeg di server untuk live preview.

Panduan instalasi (PANDUAN_INSTALASI.md) dan panduan penggunaan bergambar 33 halaman (PDF) sudah ada di dalam ZIP.

Kebutuhan dan catatan

  • PHP 8.0 atau lebih baru dengan ekstensi pdo_mysql, mbstring, gd, zip, curl. ffmpeg hanya dibutuhkan untuk live preview CCTV.
  • MySQL atau MariaDB. XAMPP sudah cukup, atau pakai hosting (lihat Pasang di hosting).
  • Menu Jaringan menjalankan ping dan arp di server lewat proc_open PHP, hanya saat tombol ditekan. Lihat PANDUAN_JARINGAN.md di dalam ZIP.
  • Pustaka pendukung sudah ada di dalam ZIP, tidak perlu composer install.
  • Dirancang untuk jaringan internal kantor. Jika dipasang di hosting, wajib pakai HTTPS dan password yang kuat.
  • Username dan password PC pada data aset disimpan sebagai teks biasa (data referensi IT). Pertimbangkan sebelum mengisinya.
  • Lisensi MIT: bebas dipakai, diubah, dan dibagikan.

Pasang di hosting (Hostinger, cPanel, dan sejenisnya)

Pasang langsung di shared hosting supaya aplikasi bisa dibuka dari mana saja. Tidak perlu SSH atau Composer.

  1. Atur PHP. Di panel hosting (Hostinger: hPanel → Advanced → PHP Configuration; cPanel: Select PHP Version), pilih PHP 8.1 atau lebih baru dan pastikan pdo_mysql, mbstring, gd, zip, curl aktif. Disarankan upload_max_filesize dan post_max_size = 64M.
  2. Buat database dulu. Di hosting tidak ada user root, jadi installer tidak bisa membuatnya sendiri. Hostinger: Databases → Management. cPanel: MySQL Database Wizard (centang ALL PRIVILEGES). Catat nama database, user, dan password, yang biasanya berawalan seperti u123456789_aset.
  3. Upload dan ekstrak. File Manager → public_html → upload asker-it-asset.zip → klik kanan → Extract. Aplikasi dibuka di https://domainanda.com/asker-it-asset/. Agar langsung di domain utama atau subdomain, pindahkan isi folder asker-it-asset ke root domain tersebut.
  4. Jalankan installer. Buka alamat aplikasi, lalu halaman instalasi muncul. Semua cek harus hijau; jika ada folder yang belum bisa ditulis, ubah permission config/, includes/data/, dan assets/uploads/ menjadi 755. Isi host localhost, nama database dan user lengkap dengan awalannya, lalu buat admin pertama dan klik Instal sekarang.
  5. Amankan. Hapus install.php dan aktifkan SSL (HTTPS) di panel hosting. HTTPS juga diperlukan agar scan QR bisa memakai kamera HP.

CCTV dan menu Jaringan di hosting

Server hosting tidak bisa langsung menjangkau jaringan kantor (alamat seperti 192.168.x.x). Aplikasi mendeteksinya dan menyediakan:

  • Cara terhubung NVR per NVR: jaringan lokal, IP publik / DDNS (port forwarding), Cloudflare Tunnel, atau Agen Kantor. Alamat RTSP & snapshot bisa diisi manual untuk merek apa pun.
  • Live preview otomatis memakai snapshot (±1–2 detik sekali) bila server tidak punya ffmpeg.
  • Cek otomatis lewat Cron Job hosting (perintah ada di CCTV → Pengaturan → 7).
  • Menu Jaringan: Topologi & Data koneksi tetap jalan; Cek & Scan muncul bila Agen Kantor aktif.

Tidak punya IP publik? Pakai Agen Kantor

Script kecil di 1 PC Windows kantor yang selalu menyala: membaca NVR, mengambil snapshot, menjalankan ping & scan, lalu mengirim hasilnya ke hosting lewat HTTPS. Hanya koneksi keluar: tanpa IP publik, port forwarding, maupun VPN. Unduh dari menu Agen Kantor, uji dengan jalankan_agen.bat, lalu jalankan pasang_agen.bat sebagai administrator.

Pindah dari server lokal? Sebelum menjalankan installer, ekspor database lama dari phpMyAdmin lokal, lalu impor file .sql-nya ke database baru lewat phpMyAdmin hosting. Installer akan mendeteksi admin yang sudah ada, jadi cukup login dengan akun lama. Salin juga assets/uploads/ dan includes/data/ agar logo, kop surat, dan foto ikut pindah.
